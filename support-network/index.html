Frequently asked questions

Support, explained clearly.

Do I need to contact the local technician directly?

No. Customers communicate directly with Zybility. When local assistance is required, Zybility coordinates the appropriate support resource.

What if there is no local support partner in my area?

Zybility will first provide remote support and determine the best available support option.

What problems can be handled remotely?

Software configuration, application issues, account problems, system settings, data synchronization and many other software-related issues can often be resolved remotely.

When is an on-site technician required?

Hardware, printer, network, cabling, Windows or physical equipment issues may occasionally require on-site assistance.

Is local support available everywhere?

Zybility's support network is continuously expanding. The map displays the current status of each active region.
